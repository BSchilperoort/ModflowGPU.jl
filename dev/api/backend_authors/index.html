For backend authors

ModflowGPU runs on any KernelAbstractions backend. Each GPU package is a weak dependency with a package extension in ext/ (for example ext/AMDGPUExt.jl), which Julia loads when the user loads the GPU package. The extension registers its backend in __init__ and adds methods to the hooks below where the default does not fit its backend:

  • ModflowGPU.register_backend! (required): makes the backend selectable by name;
  • supports_float64: false for devices without Float64 (the default is true);
  • ModflowGPU.pin_memory!: page-locked host memory for faster transfers;
  • ModflowGPU.free_memory!: release device memory immediately;
  • ModflowGPU.host_mapped_zeros: host memory that kernels can write directly.

None of these are exported; an extension calls them qualified. ModflowGPU.free_device_arrays!, which frees every device array of an object through ModflowGPU.free_memory!, is also useful to coupling code.

ModflowGPU.register_backend! — Function
ModflowGPU.register_backend!(name, package, is_functional, construct)

Register a GPU backend under name (lower case, e.g. "rocm"), so that select_backend(name) and select_backend("auto") can find it. package is the name of the GPU package (e.g. "AMDGPU"), is_functional a function () -> Bool that tells whether the GPU can be used on this machine, and construct a function () -> KernelAbstractions.Backend. Called by each package extension in its __init__. A later registration under the same name replaces the earlier one.

Example

The registration of ext/AMDGPUExt.jl:

function __init__()
    return ModflowGPU.register_backend!("rocm", "AMDGPU", AMDGPU.functional, ROCBackend)
end

ModflowGPU.pin_memory! — Function
ModflowGPU.pin_memory!(backend, arr)

Extension hook. Page-lock the host array arr to speed up transfers between it and the device. Returns nothing when nothing was done (the default, unless a backend extension adds a method for its backend), otherwise a handle the caller keeps for as long as the memory should stay pinned (CUDA: the array; ROCm: a registered ROCArray wrapper). Copies from pinned memory may run asynchronously: synchronize before overwriting it.

A backend extension adds a method for its backend type.

Example

# in ext/CUDAExt.jl
ModflowGPU.pin_memory!(::CUDABackend, arr) = CUDA.pin(arr)

ModflowGPU.free_memory! — Function
ModflowGPU.free_memory!(backend, arr)

Extension hook. Release the device memory of the device array arr now, instead of when the garbage collector finalises it (two models on one GPU, finalize_simulation). arr must not be used afterwards. The default calls KernelAbstractions.unsafe_free!, which GPU packages implement for their arrays (a no-op for host arrays); extensions add a method where the backend needs something else. Memory shared with other arrays (reshape, unsafe_wrap of the same buffer) is released when the last of them is freed. Returns nothing.

source
ModflowGPU.host_mapped_zeros — Function
ModflowGPU.host_mapped_zeros(backend, T, n) -> (device, host) or nothing

A zeroed host vector host of n values of type T and a device array device that aliases its memory (kernels write the host memory directly), or nothing when the backend cannot map host memory (callers then copy with copyto!). Used for the small results of device reductions, which the host reads after every reduction: on ROCm this saves the device-to-host copy (~30 µs on the RX 7800 XT, docs/dev/precision.md). Extension hook: the CPU backend returns the same Array twice, ROCm a registered host array; other backends return nothing unless their extension adds a method.

Example

julia> d, h = ModflowGPU.host_mapped_zeros(select_backend("cpu"), Float64, 2);

julia> d === h
true

ModflowGPU.free_device_arrays! — Function
ModflowGPU.free_device_arrays!(x) -> Int

Free (ModflowGPU.free_memory!) every device array reachable from x through struct fields, array elements and dictionary entries (host arrays of bits types are skipped, wrappers such as views are followed to their parent). Returns the number of arrays freed. Nothing reachable from x may use those arrays afterwards. Used by finalize_simulation, and by coupling code to free its own device buffers before another model allocates.

Example

buffers = (; recharge = KernelAbstractions.zeros(backend, Float32, n))
ModflowGPU.free_device_arrays!(buffers)   # 1 (0 on the CPU backend)
