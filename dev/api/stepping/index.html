Stepping API

The stepping API runs a simulation one time step at a time, as libmf6's API (XMI) does, so that another model can read and change its variables between steps. initialize builds the model; ModflowGPU.update runs one time step, or the calls it is made of (prepare_time_step, then do_time_step or prepare_solve, ModflowGPU.solve and finalize_solve, then finalize_time_step); finalize_simulation ends it. Variables are named by libmf6's addresses, such as "GWF/X" (heads) or "GWF/RIV-1/BOUND" (river data), and are read and written as host arrays in Float64 with absolute heads.

using ModflowGPU
sim = initialize("path/to/simulation"; backend = select_backend("auto"))
riv = get_value_ptr(sim, "GWF/RIV-1/BOUND")   # (3, nriv): stage, cond, rbot
while get_current_time(sim) < get_end_time(sim)
    prepare_time_step(sim)
    riv[1, :] .= my_river_stages(get_current_time(sim))
    do_time_step(sim) || @warn "no convergence"
    finalize_time_step(sim)
    heads = get_value(sim, "GWF/X")
end
finalize_simulation(sim)
ModflowGPU.Simulation — Type
Simulation

A simulation driven one time step at a time, created by initialize and used by the other functions of the stepping API. It is also the model type of the BMI methods (BasicModelInterface.initialize(Simulation, dir)).

Fields that are useful to read (do not change them):

  • spec: the SimulationSpec it was built from;
  • T, Ts, Tp: the precision types (see resolve_precision);
  • steps: the TDIS time steps, and istep, the index of the current one (0 before the first prepare_time_step);
  • results and budgets: per completed time step its StepResult and ModelBudget.

The other fields (the model on the device, the solver, the output files, the call stage) are internal.

Example

sim = initialize("path/to/simulation")
sim.istep, length(sim.steps)   # (0, number of time steps)
source
ModflowGPU.StepResult — Type
StepResult

The result of one time step, in RunResult.steps and Simulation.results.

Fields:

  • step: the TDIS time step, with kper, kstp (stress period and time step numbers), delt (step length), pertim and totim (time in the period and in the simulation at the end of the step), in the model's time units;
  • outer: the outer-iteration result, with converged::Bool, iterations (outer iterations) and inner (total inner, linear-solver, iterations).

Example

result = run_simulation("path/to/simulation")
[(r.step.kper, r.step.kstp, r.outer.iterations) for r in result.steps]

ModflowGPU.initialize — Function
initialize(simdir::AbstractString; kwargs...) -> Simulation
initialize(spec::SimulationSpec; kwargs...) -> Simulation

Start a simulation to be run one time step at a time: load the MF6 simulation in directory simdir (or take a loaded or built spec; one GWF model with one IMS solution), build the model, the outer solver and the budget accumulator on the device, and open the output files (libmf6's initialize).

The keywords are those of run_simulation: backend, precision, outdir, closures, write_output, preconditioner and precond_options.

Before the first prepare_time_step (or ModflowGPU.update) the heads are the starting heads and no period data is applied. End with finalize_simulation, which closes the output files and frees the device memory.

Throws an ModflowGPU.MF6InputError or MF6UnsupportedError for invalid or unsupported input (also for a simulation with more than one model).

Example

sim = initialize("path/to/simulation"; backend = select_backend("auto"))
while get_current_time(sim) < get_end_time(sim)
    ModflowGPU.update(sim) || error("time step did not converge")
end
finalize_simulation(sim)
source
ModflowGPU.prepare_time_step — Function
prepare_time_step(sim::Simulation, dt = 0.0) -> sim

Advance to the next TDIS time step and, at the first step of a stress period, apply the period data (libmf6's prepare_time_step). dt is ignored, as in libmf6 (no adaptive time stepping). Values set through the stepping API before this call are kept unless the period has new data for that package (as in MF6). Values written into host mirrors (get_value_ptr) are sent to the device first.

Allowed after initialize and after finalize_time_step; throws an ArgumentError otherwise, or when the simulation has ended.

Example

One time step, call by call (what ModflowGPU.update does):

prepare_time_step(sim)
prepare_solve(sim)
for _ in 1:only(get_value(sim, "SLN_1/MXITER"))
    ModflowGPU.solve(sim) && break
end
finalize_solve(sim)
finalize_time_step(sim)

ModflowGPU.prepare_solve — Function
prepare_solve(sim::Simulation, isol = 1) -> sim

Start the outer iterations of the current time step (libmf6's prepare_solve): the storage term for the step length, the heads of the previous step and the constant heads; it resets the iteration counter. Values written into host mirrors since the last call are sent to the device first, and BOUND arrays opened with ModflowGPU.device_bound! are checked. isol is the solution number; only 1 exists.

Allowed after prepare_time_step; see there for an example.

source

prepare_solve(m::MF6Model, component_id = 1) -> m: prepare_solve of the simulation.

ModflowGPU.solve — Function
ModflowGPU.solve(sim::Simulation, isol = 1) -> Bool

One outer (Picard) iteration of the current time step (libmf6's solve); returns whether the step has converged. Call it up to MXITER times (get_value(sim, "SLN_1/MXITER")). isol is the solution number; only 1 exists.

Not exported, because solve is also exported by CommonSolve (the SciML packages) and would be ambiguous next to it: write ModflowGPU.solve. See prepare_time_step for an example.

source

ModflowGPU.solve(m::MF6Model, component_id = 1) -> Bool: one outer iteration; whether the step converged.

source
ModflowGPU.finalize_solve — Function
finalize_solve(sim::Simulation, isol = 1) -> Bool

End the outer iterations of the current time step (libmf6's finalize_solve): compute the flows (the SIMVALS of the stress packages) and the budget of the step. Returns whether the step converged (libmf6 reports a failure status when it did not). isol is the solution number; only 1 exists. See prepare_time_step for an example.

source

finalize_solve(m::MF6Model, component_id = 1) -> m: finalize_solve of the simulation; non-convergence sets ModflowGPU.get_last_bmi_error.

ModflowGPU.finalize_time_step — Function
finalize_time_step(sim::Simulation) -> Bool

End the current time step (libmf6's finalize_time_step): write the output selected by OC (head file, budget file, listing file). Returns false when the step did not converge and the simulation has no CONTINUE option (libmf6 returns a failure status; run_simulation throws a ConvergenceError there), true otherwise. See prepare_time_step for an example.

source

finalize_time_step(m::MF6Model) -> m: finalize_time_step of the simulation; non-convergence (without CONTINUE) warns and sets ModflowGPU.get_last_bmi_error, as libmf6's failure status.

ModflowGPU.do_time_step — Function
do_time_step(sim::Simulation) -> Bool

Solve the current time step: prepare_solve, up to MXITER ModflowGPU.solve calls, finalize_solve (libmf6's do_time_step). Returns whether the step converged. Call prepare_time_step before it and finalize_time_step after it.

Example

prepare_time_step(sim)
# ... set boundary values of this step with set_value ...
do_time_step(sim) || @warn "no convergence"
finalize_time_step(sim)

do_time_step(m::MF6Model) -> m: do_time_step of the simulation.

ModflowGPU.update — Function
ModflowGPU.update(sim::Simulation) -> Bool

Run one full time step: prepare_time_step, do_time_step, finalize_time_step (libmf6's update). Returns the result of finalize_time_step: false when the step did not converge and the simulation has no CONTINUE option.

Not exported, because CUDA.jl exports an update (for CUDA graphs) and using CUDA, ModflowGPU would make update ambiguous: write ModflowGPU.update.

This is not BasicModelInterface.update, which throws a ConvergenceError in that case and returns nothing.

Example

sim = initialize("path/to/simulation")
ModflowGPU.update(sim) # the first time step
get_current_time(sim)  # the time at its end
source
ModflowGPU.finalize_simulation — Function
finalize_simulation(sim::Simulation; free = true) -> sim

End a simulation started with initialize (libmf6's finalize): close the output files and, with free (the default), release the device memory of the model now (ModflowGPU.free_device_arrays!) rather than when the garbage collector runs. This matters when another model on the same GPU allocates next.

Afterwards the simulation cannot be stepped, and with free = true not read either (get_value and get_value_ptr throw); device arrays obtained before (get_value_ptr(...; device = true)) must not be used, while host mirrors keep their last values. With free = false the model stays readable (run_simulation returns it) and its memory is released by the garbage collector. A second call does nothing.

ModflowGPU.finalize is the same function under its earlier name.

Example

sim = initialize("path/to/simulation")
ModflowGPU.update(sim)
finalize_simulation(sim)
source
ModflowGPU.finalize — Function
ModflowGPU.finalize(sim::Simulation; free = true) -> sim

The same function as finalize_simulation, under the name used before it was exported. Not exported, because it would clash with Base.finalize; it is kept (not deprecated) for code that calls ModflowGPU.finalize.

ModflowGPU.get_value — Function
get_value(sim::Simulation, address) -> Array
get_value(sim::Simulation, address, dest) -> dest

A new host array (or dest, filled) with the current value of the variable at address (see var_addresses), read from the engine now. Values are as in get_value_ptr: Float64 with absolute heads, Int32 indices; scalars are one-element vectors.

Example

h = get_value(sim, "GWF/X")                     # heads per model node
q = get_value(sim, "GWF/RIV-1/SIMVALS")         # river flows of the last step
kper = only(get_value(sim, "TDIS/KPER"))
source
ModflowGPU.get_value_ptr — Function
get_value_ptr(sim::Simulation, address; device = false) -> Array

A host array that mirrors the variable at address (see var_addresses), as libmf6's get_value_ptr. Values are Float64 with absolute heads (in the model's length units), indices Int32; BOUND is (ncol, maxbound), with the values before the MULTIPLIER auxiliary variable is applied.

The same array is returned on every call and stays valid until finalize_simulation. It is a copy of the engine data, filled when it is created and refreshed at the end of prepare_time_step, prepare_solve and finalize_solve. Writes into the mirror of X or BOUND are sent to the device at the next prepare_time_step or prepare_solve; writes between prepare_solve and finalize_solve are discarded with a warning (use set_value there).

With device = true: the engine array itself, on the device (values in the precision T of the simulation, indices Int32), with head-like values as offsets from "<model>/HREF" and BOUND with the multiplier applied; only for X, XOLD, HREF, IBOUND, BOUND, NODELIST and SIMVALS (HREF is the host Float64 vector of the references). No mirror is made. Write a device BOUND only through ModflowGPU.device_bound!.

Example

heads = get_value_ptr(sim, "GWF/X")          # updated by every time step
riv = get_value_ptr(sim, "GWF/RIV-1/BOUND")  # stage, cond, rbot per river cell
prepare_time_step(sim)
riv[1, :] .+= 0.1                            # raise the stages for this step
do_time_step(sim)
finalize_time_step(sim)
source
ModflowGPU.set_value — Function
set_value(sim::Simulation, address, values) -> sim

Set the variable at address (one of input_addresses) and send it to the device now. X takes absolute heads per model node (cells with IDOMAIN > 0); BOUND takes (ncol, maxbound) values (or the same values flattened), before the MULTIPLIER auxiliary variable, with head-like columns (stage, head, elevation) absolute, in the model's units. A host mirror of the address (get_value_ptr) is updated as well. The values are used from the next solve until new period data for the package replaces them.

Example

prepare_time_step(sim)
bound = get_value(sim, "GWF/WEL-1/BOUND")
bound[1, :] .= -100.0                   # pumping rate of every well
set_value(sim, "GWF/WEL-1/BOUND", bound)
do_time_step(sim)
finalize_time_step(sim)
source
ModflowGPU.device_bound! — Function
ModflowGPU.device_bound!(sim, address) -> device BOUND array

For coupling on the device: open the device BOUND array at address ("<model>/<package>/BOUND") for writing in the current time step, so that kernels of the coupled model can write boundary values without a copy to the host. Allowed only between prepare_time_step and prepare_solve (otherwise an ArgumentError). Returns the engine array, as get_value_ptr(sim, address; device = true): precision T, (ncol, maxbound), head-like columns as offsets from the reference of the record's cell (rrec), multiplier applied. prepare_solve then checks the first NBOUND records of every opened BOUND on the device (one kernel and one host-mapped flag per package): all values finite, and for RIV stage ≥ bottom and conductance ≥ 0 (riv_ck); a violation throws an MF6InputError naming the first bad record. The written values are used by the step, are replaced by new period data, and are not seen by host reads of BOUND (get_value, mirrors), which keep the values last set on the host. Writes into a device BOUND that was not opened this way are not checked (the stepping API cannot see them).

Not exported: it is for code that writes device arrays in its own kernels.

Example

prepare_time_step(sim)
bound = ModflowGPU.device_bound!(sim, "GWF/RIV-1/BOUND")   # (3, maxbound) on the device
my_stage_kernel!(bound, ...)   # write the stages (row 1) as offsets from the references
do_time_step(sim)
finalize_time_step(sim)
source

ModflowGPU.var_addresses — Function
var_addresses(sim::Simulation) -> Vector{String}

Every address that get_value, get_value_ptr and the BMI accept, as libmf6 names them, for a model <model> with stress packages <package>:

  • <model>/X, XOLD (heads now and at the end of the previous step), HREF (the per-cell reference heads), IBOUND;
  • <model>/DIS/NODEUSER, NODEREDUCED, TOP, BOT, AREA, NODES, NODESUSER;
  • <model>/<package>/BOUND, NODELIST, SIMVALS (simulated flows), NBOUND, MAXBOUND;
  • SLN_1/MXITER and TDIS/DELT, TOTIM, PERTIM, KPER, KSTP, NPER.

The writable ones are listed by input_addresses.

Example

sim = initialize("path/to/simulation")
filter(contains("/RIV"), var_addresses(sim))

input_addresses(sim::Simulation) -> Vector{String}

libmf6-compatible model

MF6Model has the BMI of libmf6 as ModflowInterface.jl wraps it (see BMI); the XMI functions above take it too. These functions exist for it only, under ModflowInterface.jl's names (not exported, call them qualified):

ModflowGPU.MF6Model — Type
MF6Model(path; backend, precision, preconditioner, precond_options, closures, outdir, write_output)
MF6Model(spec::SimulationSpec; kwargs...)

A model with the BMI of libmf6, used as ModflowInterface.jl's ModflowModel: create it with the simulation directory or its mfsim.nam (or a SimulationSpec), then call BasicModelInterface.initialize(m). The keywords are the engine settings of initialize; they are kept for every (re-)initialisation.

The BMI functions return what libmf6 returns (variable addresses, shapes and type strings, one grid per model); the XMI functions of ModflowInterface.jl (prepare_time_step, prepare_solve, ModflowGPU.solve, finalize_solve, finalize_time_step, do_time_step, get_var_address, ModflowGPU.get_var_rank, ModflowGPU.get_var_shape, ModflowGPU.get_subcomponent_count, ModflowGPU.get_last_bmi_error) take it as their first argument and return it where ModflowInterface.jl does. BMI functions that libmf6 does not implement throw an ArgumentError; Simulation has the full BMI of the specification. The simulation of an initialised model is m.simulation (nothing before BMI.initialize). As ModflowInterface.jl's ModflowModel, a model that is garbage collected is finalised (in a new task, after the collection); call BMI.finalize(m) to close the output files and free the device memory at a known point.

Example

import BasicModelInterface as BMI
using ModflowGPU
const MF = ModflowGPU

m = MF6Model("path/to/simulation"; backend = select_backend("auto"))
BMI.initialize(m)
head = BMI.get_value_ptr(m, "GWF/X")
while BMI.get_current_time(m) < BMI.get_end_time(m)
    MF.prepare_time_step(m, 0.0)
    MF.prepare_solve(m, 1)
    for _ in 1:BMI.get_value_ptr(m, "SLN_1/MXITER")[]
        MF.solve(m, 1) && break
    end
    MF.finalize_solve(m, 1)
    MF.finalize_time_step(m)
end
BMI.finalize(m)
