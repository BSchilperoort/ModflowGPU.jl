How the pages are made

The pages are made from the scripts in the examples/ folder of the repository when the manual is built. Each script:

  1. takes the input of the example from the released mf6examples.zip of the MODFLOW 6 examples, and MODFLOW 6.8.2 from its release, both downloaded and checked against a pinned sha256;
  2. sets the tight closures of the parity tests in the IMS file and runs MODFLOW 6.8.2, so that both programs solve the same input to the same closure;
  3. runs ModflowGPU on the same folder on the CPU, in :double and :single precision, with the default options;
  4. draws the figures of the MODFLOW 6 example from ModflowGPU's output, with CairoMakie;
  5. shows the head differences with MODFLOW 6, and a table of the largest head and budget differences next to the values of the parity table.

The wall times on the pages are those of the CPU of the machine that built the manual (including Julia's compilation for the first run of a session) and, from the parity table, those of an AMD Radeon RX 7800 XT. The models are small, so these times say little about the speed on large models; see Performance for that.

Running an example yourself

The scripts also run on their own, from a clone of the repository (Linux, as the mf6 binary they download is the Linux one):

julia --project=docs -e 'using Pkg; Pkg.instantiate()'
julia --project=docs examples/ex-gwf-toth.jl

The downloads, the runs and the figures (PNG files) go to docs/.cache (set MFGPU_GALLERY_CACHE for another folder). The helper functions the scripts call (example_run, run_modflowgpu, compare_with_mf6 and the plot helpers) are in docs/ExampleTools.jl; they are part of the documentation, not of the package.
