# T6.2a: cost of backtracking in production

Measured 2026-11-16 on the RX 7800 XT (Julia 1.12.6, KA 0.10.7, AMDGPU 2.11), branch
`T6.2a-backtracking` against `main` (5edc1e0), same session, no other job:

```sh
julia -t 8 --project=benchmark benchmark/run.jl rocm global5m precision=double,mixed,single precond=mc_ilu0 timed=0 ims=coupling
julia -t 8 --project=benchmark benchmark/run.jl rocm global5m precision=double,mixed,single precond=mc_ilu0 timed=0 ims=parity
```

`ims=coupling` (new, `synthetic_ims(:coupling)`) is ModflowCoupling's IMS: COMPLEXITY
COMPLEX (so BACKTRACKING_NUMBER 20), SIMPLE under-relaxation 0.99, OUTER_DVCLOSE 5 m,
INNER_DVCLOSE 5 m, INNER_RCLOSE 10 STRICT, BiCGSTAB. With backtracking, every outer
iteration computes the residual L2 norm (one device reduction) and stores the heads
before the update (`hprev`, one vector write).

| IMS | precision | daily step (s) main → T6.2a | total 31 steps (s) | outer/inner per daily step | peak GiB |
| --- | --- | --- | --- | --- | --- |
| coupling | `:double` | 0.071 → 0.072 | 3.50 → 3.53 | 2.0 / 3.0 (both) | 4.253 → 4.302 |
| coupling | `:mixed` | 0.065 → 0.066 | 3.04 → 3.07 | 2.0 / 3.0 (both) | 4.057 → 4.106 |
| coupling | `:single` | 0.050 → 0.051 | 2.61 → 2.63 | 1.8 / 2.7 (both) | 2.867 → 2.892 |
| parity (no backtracking) | `:double` | 0.218 → 0.218 | 9.60 → 9.60 | 8.3 / 26.1 (both) | 4.204 → 4.204 |
| parity (no backtracking) | `:mixed` | 0.199 → 0.199 | 8.59 → 8.59 | 8.3 / 26.1 (both) | 4.007 → 4.007 |
| parity (no backtracking) | `:single` | 0.084 → 0.084 | 3.53 → 3.54 | 5.2 / 13.0 (both) | 2.842 → 2.842 |

With the coupling IMS, global5m checks the residual in all 67 outer iterations (62 in
`:single`) of the steady state and 30 daily steps but never reduces a head change, so
the iterations and heads equal `main`'s; the cost is about 1 ms per daily step (1.5 %)
and 50 MB (`hprev`, 6.6 M cells in Float64). Without backtracking nothing changes.
