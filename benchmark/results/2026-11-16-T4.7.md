## Phase 4 targets

| Target | before (main) | T4.7 | status |
| --- | --- | --- | --- |
| daily step < 0.2 s `:double` (global5m) | 0.321 s | 0.217 s (`:mixed` 0.201) | missed by 8 % |
| daily step < 0.1 s `:single` | 0.119 s | 0.086 s | met |
| steady + 30 steps < 10 s | 13.31 s `:double` / 10.85 s `:mixed` | 9.61 s / 8.74 s (`:single` 3.55) | met |
| indus < 40 µs per inner iteration | 83 µs MC-ILU0, 55 µs Jacobi | 74 µs, 47 µs | missed |
| assembly < 4 ms per outer iteration | 5.7 ms | 4.98 ms (`:double` 4.9, `:single` 3.4) | missed in `:mixed`/`:double`, met in `:single` |

- **Daily step `:double`**: what is left per outer iteration is bandwidth-bound work
  (assembly ≈ 1.8 GB, SpMV, MC-ILU0 application and the update at 80–90 % of the triad);
  8.3 outer iterations per step come from OUTER_DVCLOSE 1e-9. Getting under 0.2 s needs
  fewer bytes per entry in the assembly (`condsat` and `Δr` per entry instead of through
  `jas`, a smaller node→record map) or fusing the CG update into the preconditioner
  kernels (changes the summation order of the norms).
- **indus latency**: one CG iteration with MC-ILU0 is now 4 kernels (SpMV + direction
  + dot, update + reductions, forward, backward + r·z) and one host synchronisation; at
  ≈ 5 µs host time per launch plus ≈ 18 µs from launch to the host seeing completion, the
  floor is ≈ 40 µs before any GPU work, so < 40 µs needs fewer launches than one per
  kernel (persistent kernels or graph launches), which KA does not offer.
- **Assembly**: the fused row kernel moves ≈ 36 B per matrix entry (`ja`, `jas`, `condsat`
  and `Δr` through `jas`, neighbour `ibound` and `h`) and the package node maps 4 B per node
  per package; < 4 ms in Float64 needs a smaller layout (see above).

## Production configuration

The coupled run uses BiCGSTAB at closure 0.01 (T5.6: 3 outer / 5 inner iterations per
day). The setup changes (incremental MC-ILU0 setup, contiguous diagonal), the scale-free
operator rows, the single-pass reductions and the assembly changes apply there too; the
CG-only changes (fused direction, skipped last application) do not. The real global replay
of T5.6 was not re-timed in this card.
