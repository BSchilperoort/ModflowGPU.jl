# T5.4: Phase 4 numbers where Milestone B runs

Measured 2026-11-14 on the machine of `2026-11-07.md` (RX 7800 XT, Julia 1.12.6), branch
`T5.4-mgv-one-gpu`, nothing else on the GPU:

```sh
julia -t 8 --project=benchmark benchmark/run.jl rocm indus global5m precision=double,mixed,single precond=jacobi,mc_ilu0 timed=1
```

Environment: the root workspace re-resolved from scratch (KA 0.10.7, KernelInterface
0.4.6, AMDGPU 2.11.0, GPUArrays 12.2.0, GPUCompiler 2.22.2, Adapt 4.8.0). The shared
environment of the coupled example (ModflowGPU + ModflowCoupling + mGV `main` 42aebaa +
AMDGPU, `examples/mgv_coupling` of ModflowCoupling patch 0004) resolves to the same
versions of every package of the GPU stack (`docs/compat.md`); the harness itself needs
TimerOutputs, so it runs in the `benchmark` project. KA 0.10.5 → 0.10.7 is bitwise
neutral (`docs/compat.md`). Source changes of T5.4 in the hot loop: none (`finalize`
frees memory, `device_bound!` checks run only for opened BOUND arrays, the AMG rebuild
frees the previous hierarchy).

Models, closures and columns as in `2026-11-08-T4.5.md` (steady + 30 daily steps,
`synthetic_ims(:parity)`).

Iterations (outer / inner, steady and per step), Δh and peak memory are identical to T4.5
and T5.0 in every row. Times are within ±3 % of T4.5 except indus `:double` MC-ILU0
(0.10 vs 0.09 s steady, 0.20 vs 0.19 s total: +5 %, one rounding digit at this size) and
global5m `:single` MC-ILU0 (4.88 vs 4.72 s total, +3.4 %; daily 0.124 vs 0.120 s). The
default (`:mixed` MC-ILU0) is 10.91 s for global5m (T4.5: 10.82 s) and 0.18 s for indus:
**the Phase 4 numbers hold in the KA/AMDGPU versions of the shared environment.**

Timed runs (section split) match T5.0 within a percentage point per category (global5m
`:mixed` MC-ILU0: assembly 13.5 %, SpMV 24.8 %, preconditioner 37.8 %, reductions and
updates 14.4 %, host transfers 2.0 %).

## Storage `rho` on a change of step length

`set_timestep!` (host comprehension `sc/delt` in Float64, cast, host → device copy) when
the step length changes, global5m (6.59 M nodes), rocm: median 11.0 ms (`:single`),
20.6 ms (`:mixed`) over 12 changes. Monthly periods change the length up to 12 times a
year, so ≤ 0.25 s per simulated year against a monthly step of hundreds of ms; daily
periods never. Left as is.

## T4.7 (carried-over Phase 4 targets)

The four targets are missed by the same margins as in T4.5 (global5m daily 0.265 s
`:mixed`, 0.327 s `:double`, 0.124 s `:single`; 31 steps 10.91 s; indus 83 µs per inner
iteration; assembly unchanged). T4.7's rule is to start it only when ModflowGPU, not
mGV, limits the coupled daily step. On the Indus 1-year coupled run (rocm, `:mixed`, GPU
engine default closure 0.01) mGV takes 1.70 ms and MODFLOW plus the exchange 1.20 ms per
day (`docs/precision.md`, T5.4): **mGV dominates, so T4.7 is not needed on the Indus
numbers.** The global ratio (MODFLOW global5m 0.265 s per daily step at the parity
closures) is not known until T5.5a measures mGV at global size; decide T4.7 with those
numbers.
